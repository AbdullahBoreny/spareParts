# SparePartsHub | Cross-Platform Spare Parts Marketplace 🛠️

**SparePartsHub** is a cross-platform application built with **.NET MAUI** that provides a user-friendly marketplace for spare parts across industries like automobiles, computers, and electronics.

## Key Features
- **Multi-Shop Management:** Companies can register and manage multiple shops, each with its own inventory.  
- **Advanced Search & Filtering:** Customers can browse and filter parts by category, company, or shop.  
- **Role-Based Access:** Company admins oversee multiple shops, shop managers manage local inventories, and system admins maintain platform governance.  
- **Cross-Platform:** Runs seamlessly on Android, iOS, Windows, and macOS with a unified codebase.  

The system is designed to **connect spare part suppliers with consumers efficiently** and provides a foundation for future enhancements like intelligent recommendations and predictive inventory management.
